Case Studies
PROJECT_01
Investment Analyst Agent
Multi-Agent · FinTech
A 3-agent LangGraph orchestration system that automates institutional-grade investment research. The Data Agent retrieves live market data and financials; the Sentiment Agent processes news and social signals through NLP models; the Synthesis Agent reconciles signals from both upstream agents to generate a structured investment thesis with confidence scoring. The architecture uses LangGraph's stateful graph model to handle branching logic, retries, and conditional routing — eliminating analyst hours per report cycle.
LangGraph LangChain FastAPI Azure AI Python
PROJECT_02
AI-Powered HR Parser
Automation · HR Tech
An intelligent resume processing pipeline that automates the top-of-funnel hiring workflow. CVs ingested in any format are parsed, normalized, and scored against configurable job criteria using LLM-based extraction with structured output validation. Automated scoring logic ranks candidates on technical fit, experience alignment, and keyword density — results are persisted to Supabase with real-time recruiter dashboards. Reduced initial screening time from days to under 4 minutes per batch.
LangChain Supabase FastAPI React PDF Parsing
PROJECT_03
Shikayat.pk
Civic Tech · Sentiment AI
A civic complaint resolution platform for Pakistan with an AI backbone for real-time sentiment analysis and urgency classification. Complaints submitted by citizens are automatically triaged by an NLP pipeline that scores emotional intensity, categorizes issue type, and flags escalation-worthy cases — routing them to the appropriate authority tier. The sentiment tracking layer surfaces aggregate dissatisfaction trends by region and department, giving administrators an operational intelligence layer that manual review never could.
